# کادوچی — پلتفرم خرید کادو از لیست آرزو (Cloudflare Worker + D1 + R2)

> «کادوچی» اسم موقت است؛ در `src/views/layout.tsx` عوضش کنید.

## جریان اصلی
1. **فروشگاه** ثبت‌نام می‌کند ← مدیر پلتفرم تأیید می‌کند ← فروشگاه محصول (با عکس) ثبت می‌کند.
2. **کاربر** محصولات را می‌بیند، لیست آرزو می‌سازد (با آدرس ارسال محرمانه) و محصولات را با تعداد و یادداشت (رنگ، سایز…) اضافه می‌کند.
3. لینک لیست (`/w/<کد تصادفی>`) را به اشتراک می‌گذارد.
4. **خریدار** بدون نیاز به ثبت‌نام یک آرزو را انتخاب می‌کند، نام/موبایل/پیام کارت هدیه (و گزینه ناشناس) را وارد می‌کند و از زرین‌پال پرداخت می‌کند. **آدرس گیرنده هیچ‌وقت به خریدار نشان داده نمی‌شود.**
5. بعد از پرداخت، **برای فروشگاه در بله/تلگرام پیام می‌رود**: «این محصول را برای این گیرنده با این آدرس ارسال کن» + پیام کارت هدیه + لینک سفارش. سفارش در پنل فروشگاه هم ثبت است.
6. فروشگاه کد رهگیری ثبت می‌کند ← صاحب لیست وضعیت و پیام‌های تبریک را در صفحه لیستش می‌بیند.

## نکات فنی مهم
- **رزرو هم‌زمان**: وقتی کسی وارد پرداخت می‌شود، آن واحد ۲۰ دقیقه رزرو می‌شود (یک INSERT اتمی در D1)، پس دو نفر یک آرزو را هم‌زمان نمی‌خرند. اگر پرداخت نکرد، رزرو خودکار آزاد می‌شود.
- آدرس در لحظه پرداخت از لیست کپی می‌شود (اگر بعداً آدرس لیست عوض شود، سفارش‌های قبلی دست نمی‌خورند).
- بازگشت دوباره به صفحه callback پرداخت، سفارش را دو بار ثبت و پیام تکراری نمی‌فرستد.
- مبالغ به **تومان** ذخیره و با `currency: IRT` به زرین‌پال فرستاده می‌شوند.
- تصاویر در R2، رمزها با PBKDF2، کوکی HttpOnly، محافظت CSRF.

## راه‌اندازی روی Cloudflare
```bash
cd shop
npm install
npx wrangler d1 create shop                  # database_id را در wrangler.jsonc بگذارید
npx wrangler r2 bucket create gift-shop-images
npm run db:migrate:remote
# در wrangler.jsonc مقدار SITE_URL را آدرس واقعی سایت بگذارید
npx wrangler secret put SETUP_TOKEN
npx wrangler secret put ZARINPAL_MERCHANT_ID
npx wrangler secret put BALE_BOT_TOKEN       # از @BotFather در بله
npx wrangler secret put BOT_WEBHOOK_SECRET   # یک رشته تصادفی
npm run deploy
```
- اولین مدیر: `/setup` با `SETUP_TOKEN`.
- وصل کردن بات (تا بات به فروشگاه‌ها شناسه چتشان را بگوید):
  `https://tapi.bale.ai/bot<TOKEN>/setWebhook?url=<SITE_URL>/bot/bale/<BOT_WEBHOOK_SECRET>`
  (برای تلگرام: `TELEGRAM_BOT_TOKEN` و `api.telegram.org` با مسیر `/bot/telegram/...`)
- تست زرین‌پال: `ZARINPAL_SANDBOX` را `"1"` بگذارید.

## اجرای محلی
```bash
cd shop && npm install
printf 'SETUP_TOKEN="local"\nDEV_PAYMENTS="1"\n' > .dev.vars   # DEV_PAYMENTS = درگاه آزمایشی، فقط محلی
npm run db:migrate:local
npm run dev                                  # http://localhost:8788
```
تست‌ها: `npm test` — بررسی تایپ: `npm run typecheck`

## هنوز پیاده نشده (قدم‌های بعدی پیشنهادی)
- **تسویه با فروشگاه‌ها و کمیسیون**: پول به حساب درگاه پلتفرم می‌آید؛ صفحه مدیریت جمع فروش هر فروشگاه را نشان می‌دهد ولی پرداخت به فروشگاه دستی است.
- ورود با کد یکبارمصرف پیامکی (الان موبایل + رمز است) و پیامک به فروشگاه/گیرنده.
- خرید گروهی (چند نفر روی یک کادوی گران سهم بگذارند).
- موجودی انبار، دسته‌بندی محصولات، چند عکس برای هر محصول.
- محدودیت تعداد تلاش ورود (rate limit).
